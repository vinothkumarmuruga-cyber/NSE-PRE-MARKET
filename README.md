# NSE Pre-Open Dashboard

Streamlit dashboard for:

- NSE pre-open data
- Top 5 gainers
- Top 5 losers
- Nearest CE/PE strikes
- Previous day/week/month levels
- Previous CE/PE close
- BEP calculation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Push `app.py` and `requirements.txt` to GitHub.

Then deploy the repository using Streamlit Community Cloud.

Main file:
`app.py`
